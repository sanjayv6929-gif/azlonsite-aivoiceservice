# Azlon AI — AI Voice Agent website

Landing page for Azlon AI's speed-to-lead AI voice agents. Plain static site: one `index.html` plus images, audio and video. No build step.

## Files
- `index.html` — the whole page (styles and scripts inline)
- `audio/` — voice agent demo recordings
- `reels/` — Instagram reel videos (`.mp4`) and poster images (`.jpg`)
- `logo.png`, `founder.jpg` — brand logo and founder photo
- `favicon.ico`, `favicon-96x96.png`, `apple-touch-icon.png`, `web-app-manifest-*.png`, `site.webmanifest` — icons

## Editing content
Near the bottom of `index.html`, the `DEMOS` and `REELS` lists hold the demo titles, reel videos, links and view counts.

## Deploy
Works on any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages). Publish directory: the repo root. Build command: none.
